# BiliSing 点播系统 (v2.0)

[Changelog](CHANGELOG.md) | [Terms of Service & Privacy Policy](TERMS_AND_PRIVACY.md)

BiliSing 是一款哔哩哔哩视频点播系统。通过简单的房间号连接，多名用户可以同时参与点播，并在一台核心“播放设备”（如电脑、平板或运行 BiliSing App 的安卓设备）上集中播放。

## 🌟 新特性

  * **智能搜索点播**：直接在网页内搜索哔哩哔哩视频，支持关键词匹配，无需再手动切换 App 复制链接。
  * **多分 P 支持**：完美解析多 P 视频，支持选择特定分 P 进行点播，时长统计更精确。
  * **DLNA 投屏 (Android)**：全新安卓客户端支持将视频流一键投屏至智能电视或投影仪。
  * **互动增强**：集成 Edge TTS 语音合成，用户发送的消息可自动语音朗读，提升聚会氛围。

-----

## 🛠️ 使用流程

### 1\. 创建/作为播放设备 (Master)

  * **电脑端**：访问网页，用户类型选择「播放设备」，点击加入房间。
    > **注意**：电脑端作为播放器需安装配套浏览器插件 `bilising.user.js` 以获得最佳兼容性。
  * **移动端**：建议安装 **BiliSing App** (iOS/Android)。在网页选择「播放设备」时，系统会自动引导跳转或下载。

### 2\. 加入房间点播 (Slave)

  * **快速加入**：扫描播放设备屏幕上显示的 **二维码** 即可直接进入房间。
  * **手动加入**：访问网页，输入对应的房间 ID，选择「点播设备」并输入你的昵称。

### 3\. 如何点播

  * **方式 A**：点击「搜索视频」按钮，输入关键词查找并点击确认添加。
  * **方式 B**：在 Bilibili 客户端分享视频，复制链接并粘贴到输入框中点击「➕」。

### 4\. 播放与管理

  * **队列控制**：点播者可以对列表中的歌曲进行上移、下移或删除操作。
  * **即时交流**：在聊天框发送消息，播放设备将实时显示并自动语音朗读（Android App 通过 DLNA 投屏时不支持）。
  * **切歌确认**：为防止误触，点播端的“切歌”采用双击确认机制。

## 🚀 部署指南

### 方法一：快速启动（推荐）

如果你在类 Unix 系统（Linux/macOS）下，可以直接运行：

```bash
chmod +x start.sh
./start.sh
```

### 方法二：手动安装

1.  **安装 Python 依赖**：
    ```bash
    pip3 install -r requirements.txt
    ```
2.  **启动应用**：
    ```bash
    python3 app.py
    ```

### 访问应用

默认端口为 `11817`，启动后访问：
`http://<你的服务器IP>:11817`

-----

## 📝 部署注意事项

1.  **数据持久化**：目前所有房间数据（播放列表、聊天记录）均存储在内存中。**重启服务会导致数据清空**。
2.  **网络环境**：请确保播放设备与服务端、以及点播用户与服务端之间的网络互通。投屏功能要求安卓设备与电视在同一局域网下。
