# BiliSing 卡拉OK点歌系统

BiliSing 是一个基于哔哩哔哩视频的卡拉OK点歌系统。用户可以通过分享哔哩哔哩视频链接来点歌，支持多设备协同使用。

## 功能特点

- 🎵 支持哔哩哔哩视频点歌
- 📱 分离式设计：播放设备和点歌设备分开
- 🔄 实时同步：使用 Socket.IO 实现实时数据同步
- 📝 播放列表管理：支持删除歌曲和调整播放顺序
- 🎮 简单易用：无需数据库，所有数据存储在内存中

## 安装和运行

### 方法一：使用启动脚本（推荐）

```bash
# 直接运行启动脚本
./start.sh
```

### 方法二：手动安装

```bash
# 1. 安装 Python 依赖
pip3 install -r requirements.txt

# 2. 启动应用
python3 app.py
```

### 访问应用

启动成功后，在浏览器中打开：
```
http://localhost:11817
```

## 使用说明

### 1. 创建房间

下载 APP 并根据相关指引操作

### 2. 加入房间点歌

1. 选择"点歌设备"类型
2. 输入相同的房间ID和用户名
3. 点击"加入房间"

### 3. 点歌操作

在点歌设备上：
- 复制哔哩哔哩视频分享链接
- 粘贴到输入框中
- 点击"点歌"按钮

### 4. 播放控制

在播放设备上：
- 自动播放当前歌曲
- 查看点歌设备发送的信息

### 5. 播放列表管理

在点歌设备上可以：
- 上移/下移歌曲调整播放顺序
- 删除不需要的歌曲

### 部署注意事项

1. **端口配置**: 默认使用11817端口，可在 `app.py` 中修改
2. **跨域设置**: 已配置 `cors_allowed_origins="*"`，生产环境建议限制域名
3. **内存使用**: 所有数据存储在内存中，服务重启后数据会丢失
