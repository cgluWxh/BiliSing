# BiliSing 点歌系统
[Changelog](CHANGELOG.md) | [Terms of Service & Privacy Policy](TERMS_AND_PRIVACY.md)

BiliSing 是一个基于哔哩哔哩视频的点歌系统。多名用户可以通过分享哔哩哔哩视频链接来点歌，并在一台播放设备上进行播放。用户亦可将播放设备的画面投屏到大屏幕上，适合多人聚会使用。

## 使用说明

### 1. 创建房间

安卓/iOS 设备上: 安装对应客户端后按指引进行 (可通过网页版访问后选择设备类型为「播放设备」后自动跳转到 APP 下载)

### 2. 加入房间

#### 在手机上

1. 扫描播放设备上显示的点歌二维码
2. 输入用户名
3. 点击"加入房间"

#### 在电脑上

1. 打开网页版，选择"点歌设备"类型
2. 输入相同的房间ID和用户名
3. 点击"加入房间"

### 3. 点歌操作

在点歌设备上：
- 在官方哔哩哔哩客户端中，复制视频分享链接
- 将复制的完整内容直接粘贴到输入框中
- 点击"点歌"按钮

### 4. 播放控制

在点歌设备上可以：
- 切换到下一首
- 上移/下移歌曲调整播放顺序，删除歌曲
- 重新播放已播放过的歌曲
- 发送信息，查看发送的信息

### 部署注意事项

1. **端口配置**: 默认使用11817端口，可在 `app.py` 中修改
2. **跨域设置**: 已配置 `cors_allowed_origins="*"`，生产环境建议限制域名
3. **内存使用**: 所有数据存储在内存中，服务重启后数据会丢失

## 部署服务端

### 方法一：使用启动脚本（推荐）

```bash
# 直接运行启动脚本
./start.sh
```

### 方法二：手动安装

```bash
# 1. 安装 Python 依赖
pip3 install -r requirements.txt

# 2. 启动应用
python3 app.py
```

### 访问应用

启动成功后，在浏览器中打开：
```
http://localhost:11817
```
